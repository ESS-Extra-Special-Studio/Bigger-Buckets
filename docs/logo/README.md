# Bigger Buckets logo

The Skills of Ashenfall gold frame with a wooden bucket overflowing past its brim in the centre. The bucket is drawn by the logo generator, not taken from the game. Not packed into the release zip.

- `bigger-buckets-logo-plain-*.png`: no text. Use for the CurseForge project logo.
- `bigger-buckets-logo-series-*.png`: "Extra Special Studio" ribbon.
- `bigger-buckets-logo-named-*.png`: "Bigger Buckets" ribbon with a small "Extra Special Studio" plaque.

Sizes 1024 (master), 512, 400 and 256 (preview). Master copy, frame sources, rules and the generator live in Extra Special Studio's `Dragonwilds\branding\` folder (see "Logo system" in `DRAGONWILDS_MASTER.md`). Regenerate there rather than editing these files, and never put them in `BiggerBuckets\`.
